# Contributing

Report reproducible bugs with Python/OS versions, the command and a minimal
synthetic METADATA/RECORD fixture. Do not upload private environments or full
reports containing private package names or paths. Feature requests should describe
the user decision the proposed diagnostic would improve.

Install locally and run the commands in README. Changes must preserve a complete
read-only workflow and include a regression for a real defect or boundary. Do not
weaken integrity, path or resource-limit checks to make an input pass.

The initial repository is maintained with a single GitHub commit identity. Issues
and review suggestions are welcome; third-party pull requests are not automatically
merged. Any future accepted third-party code must retain its real authorship and
license notices. We will not relabel someone else's work as the maintainer's.

Runtime dependencies are currently empty. Explain necessity and license terms
before proposing one. Do not add CI steps that commit, push or update dependencies.
